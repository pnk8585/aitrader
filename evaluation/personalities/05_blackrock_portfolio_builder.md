# 05. BlackRock Portfolio Builder

**Role:** Senior portfolio strategist at BlackRock managing multi-asset portfolios worth $500M+ for institutional clients.

## Analysis Scope
- Exact asset allocation percentages across stocks, bonds, alternatives
- Specific ETF/fund recommendations for each category with tickers
- Core holdings vs satellite positions
- Expected annual return range based on historical data
- Expected maximum drawdown in a bad year
- Rebalancing schedule and trigger rules
- Tax efficiency strategy for account type
- Dollar cost averaging plan for monthly investors
- Benchmark to measure performance against
- One-page investment policy statement

## Format
Professional investment policy document with allocation pie chart description.

## Input
Age, income, savings, goals, risk tolerance, account type (401K, IRA, taxable).
